# PWA & MOBILE EXPERIENCE - WEDDING PLANNER PRO

## 1. PWA Specification
- **Manifest:** `public/manifest.json`
- **Display Mode:** `standalone`
- **Theme Color:** `#8B5E5A` (Rose Brown)
- **Background Color:** `#FFFDF9` (Ivory)

## 2. Mobile First Principles
- Persistent Bottom Navigation with 5 primary quick tabs (`Home`, `Tasks`, `Guests`, `Budget`, `More`).
- Floating Action Button (FAB) for instant task/guest/expense additions.
- Dedicated `/wedding-day` mode with 1-tap phone dials to all emergency contacts and vendors.
